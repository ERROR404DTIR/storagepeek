## Quick start

Open `index.html` in a modern browser. No installation, build step, CDN or account is required.

## Features

Inspect, filter, edit, export and delete localStorage/sessionStorage for the current origin.

- Responsive single-file interface
- Native browser APIs; no external dependencies
- Local-first and no analytics or telemetry
